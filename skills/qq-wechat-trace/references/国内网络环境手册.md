# 国内网络环境配置手册

**适用**：在中国大陆网络环境下从零搭建 QQ/微信聊天记录导出环境
**日期**：2026-09-25
**配套**：`README.md`（总览）、`WINDOWS.md`（Windows 专项）

---

## 0. 一句话结论

**这个项目的依赖极轻 —— Python + 一个 pip 包 + Node。国内源完全够用，不需要代理。**

本机实测（2026-09-25）：

| 项目 | 状态 |
|---|---|
| `sqlcipher3==0.6.2` 从阿里云源下载 | ✅ 成功，有 Windows 预编译包 |
| Node v24.14.1 `zstdDecompressSync` | ✅ 可用 |
| `bsdtar 3.8.8` | ✅ Win10 1803+ 自带 |
| 阿里云 PyPI 镜像可达 | ✅ HTTP 200 |
| 华为云 npm 镜像可达 | ✅ HTTP 200 |

**唯一需要联网的地方**：QQ 密钥脚本要从上游拉代码（见第 4 节）。
好消息是它现在内置 4 个镜像地址自动回退，国内多数情况**不用配代理**。

## 1. 换国内源（两条命令）

### pip → 阿里云

```powershell
python -m pip config set global.index-url https://mirrors.aliyun.com/pypi/simple
python -m pip config set global.trusted-host mirrors.aliyun.com
```

**手动写法**（等价，写文件更稳）：把下面内容存成
`%APPDATA%\pip\pip.ini`

```ini
[global]
index-url = https://mirrors.aliyun.com/pypi/simple
trusted-host = mirrors.aliyun.com
```

### npm → 华为云

```powershell
npm config set registry https://repo.huaweicloud.com/repository/npm/
```

或写文件 `%USERPROFILE%\.npmrc`：

```ini
registry=https://repo.huaweicloud.com/repository/npm/
```

**注意**：本项目的 Node 脚本**只用内置模块**（`node:zlib` / `node:fs` / `node:path`），
**一个 npm 包都不装**。所以 npm 源其实不是必需品——但如果要用 Trae / AI 编程工具，
它们自己会拉包，配好更省事。

---

## 2. 装 Python 依赖

```powershell
python -m pip install sqlcipher3==0.6.2
```

**为什么锁 0.6.2**：这是当前有 `cp314` 预编译 wheel 的版本，**装了就能用，不用编译器**。
实测下载到的是 `sqlcipher3-0.6.2-cp314-cp314-win_amd64.whl`（2.6 MB）。

**验证**：

```powershell
python -c "import sqlcipher3; print('OK')"
```

**如果报错**：多半是 Python 版本对不上。本项目的目标版本是 **3.13 或 3.14**。
Python 3.12 以下的 wheel 名字不同，一般也能装，但没实测过。

---

## 3. 装 Node

**要求 ≥ 23.8**（为了 `zlib.zstdDecompressSync`，微信解码必需）。

国内下载 Node 的途径：
- 官网 `nodejs.org`（可能慢）
- 华为云镜像：`https://mirrors.huaweicloud.com/nodejs/`
- 淘宝镜像：`https://npmmirror.com/mirrors/node/`

**验证**：

```powershell
node -e "console.log(!!require('zlib').zstdDecompressSync)"
```

必须输出 `true`。输出 `false` 或报错说明版本太低，**微信那一步会失败**。

## 4. 唯一需要代理的地方：QQ 密钥脚本

`scripts/fetch_qq_key.ps1` 会从 GitHub 拉上游代码：

```
https://raw.githubusercontent.com/QQBackup/qq-win-db-key/master/scripts/windows/ntqq/windows_ntqq_get_key.ps1
```

**为什么不在仓库里自带**：上游是**非商用开源协议**，跟本仓库的 MIT 不兼容，
所以改成"运行时拉取 + 打补丁"。

### 解法 A：手动下载（推荐，不用代理）

让能上 GitHub 的人在浏览器打开那个链接，存成本地文件，然后：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\fetch_qq_key.ps1 -LocalPath <下载的文件>
```

也可以用 jsDelivr（国内一般可达，不用麻烦别人帮忙下载）：
`https://cdn.jsdelivr.net/gh/QQBackup/qq-win-db-key@master/scripts/windows/ntqq/windows_ntqq_get_key.ps1`

### 解法 A2：脚本内置多镜像，自动回退（2026-10-27 起）

`fetch_qq_key.ps1` 现在按顺序尝试 4 个地址，前一个失败自动换下一个：

| # | 地址 | 2026-10-27 实测 |
|---|---|---|
| 1 | `raw.githubusercontent.com/QQBackup/...` | ✅ 200（直连可用时） |
| 2 | `cdn.jsdelivr.net/gh/QQBackup/...` | ✅ 200 |
| 3 | `gcore.jsdelivr.net/gh/QQBackup/...` | ✅ 200 |
| 4 | `gh-proxy.com/https://raw.githubusercontent.com/...` | ✅ 200 |

4 个地址返回的是**同一份文件**（44,107 字节），内容一致。
**不用配代理、不用改脚本**，直接跑 `scripts\fetch_qq_key.ps1` 即可。

### 解法 B：给 PowerShell 配代理

```powershell
# 只在当前窗口生效
$env:HTTP_PROXY  = 'http://127.0.0.1:7890'
$env:HTTPS_PROXY = 'http://127.0.0.1:7890'
```

（端口按你自己的代理软件填。）

### 解法 C：干脆跳过

**把已经提好的密钥文件直接拷过来**——密钥有粘性，跨重启不变：

```
keys\QQ_DB_KEY_<QQ号>.txt      16 字节
keys\wechat_keys.json          34 把
keys\wx_db_key_map.json        盐值映射
```

**这条路最省事，也是推荐做法。**

## 5. 微信密钥：国内网络无影响

`scripts/wx_mem_scan.py` 扫的是**本机进程内存**，**不联网**。

唯一的限制是系统权限：读别的进程内存**必须管理员权限**。

```powershell
# 用管理员身份开 PowerShell，然后
python scripts\wx_mem_scan.py
```

## 6. 用 Trae CN / 国内 AI 工具时怎么跟它说

**前提认知**：Trae / Cursor / Copilot 这类工具的作用是**帮你写代码、改配置**，
**它们不会替你装环境**。所以"用 Trae 走国内渠道安装"这个说法要拆成两件事：

| 想做的事 | 工具能不能帮 |
|---|---|
| 帮你改 `config.json` 的路径 | ✅ 能 |
| 帮你排查报错 | ✅ 能 |
| **替你执行 pip / npm 安装** | ❌ **不能**，还是你自己跑命令 |

所以实际意义是：**让 AI 帮你把命令写对、把坑避开**，然后你自己执行。

### 可以直接贴给它的话

```
我要在 Windows 上跑一个 QQ/微信聊天记录导出工具，环境要求：

1. Python 3.13 或 3.14，需要 sqlcipher3==0.6.2
2. Node ≥ 23.8（需要 zlib.zstdDecompressSync）
3. 我这台机器在中国大陆，用国内镜像：
   - pip 用 https://mirrors.aliyun.com/pypi/simple
   - npm 用 https://repo.huaweicloud.com/repository/npm/

请帮我：
a) 写好 pip.ini 和 .npmrc 的完整内容（含 trusted-host）
b) 给我验证每一步是否装好的命令
c) 如果 sqlcipher3 装不上，告诉我是 Python 版本问题还是源的问题

注意：不要建议我装编译器，这个包应该有 Windows 预编译 wheel。
```

### 让它别做的事

```
- 不要让我 pip install 的时候加 --no-binary
- 不要把 pip 源改成清华源（阿里云那个已实测可用）
- 不要建议装 Visual Studio Build Tools（不需要）
```

## 7. 完整检查清单（新机器）

```powershell
# ① Python 与依赖
python --version                                                  # 3.13 / 3.14
python -c "import sqlcipher3; print('sqlcipher3 OK')"

# ② Node
node --version                                                    # >= v23.8
node -e "console.log(!!require('zlib').zstdDecompressSync)"       # true

# ③ tar
tar --version                                                     # bsdtar

# ④ 镜像源
python -m pip config list                                         # 应显示阿里云
npm config get registry                                           # 应显示华为云

# ⑤ 项目配置
python scripts\trace_config.py                                    # 打印有效配置
```

`trace_config.py` 的输出**只打印路径，绝不打印密钥内容**。

## 8. 哪些步骤要联网 / 哪些不要

| 步骤 | 要联网？ |
|---|---|
| 装 Python / Node / sqlcipher3 | ✅ 要（走国内镜像） |
| 拉 QQ 密钥上游脚本 | ✅ 要（GitHub；**脚本有 4 个镜像自动回退**，国内多数情况不用代理） |
| 扫微信密钥（`wx_mem_scan.py`） | ❌ **不联网**，纯本地内存扫描 |
| QQ 剥头 / 导出 | ❌ 不联网 |
| 微信分片复制 / 导出 | ❌ 不联网 |
| zstd 解码 | ❌ 不联网 |
| 对账 | ❌ 不联网 |

**核心结论**：**装完之后，整个导出流程 100% 离线**。这是有意设计的——
聊天记录是敏感数据，不该在导出过程中过网络。

## 9. 遇到的坑与解法速查

| 症状 | 原因 | 解法 |
|---|---|---|
| `pip install sqlcipher3` 开始编译 | 源里没这个 Python 版本的 wheel | 换 Python 3.13/3.14，或加 `--only-binary=:all:` |
| `ModuleNotFoundError: sqlcipher3` | 装到了别的 Python 环境 | 用 `python -m pip` 而不是裸 `pip` |
| `zstdDecompressSync` 不是函数 | Node < 23.8 | 升级 Node |
| `fetch_qq_key.ps1` 拉取失败 | 4 个地址都不可达 | 用 `-LocalPath` 手动指定；或带上已有密钥跳过这步 |
| `微信未运行` | 微信没开 | 开微信并**点开要导的群**，再重跑 |
| `OpenProcess failed` | 权限不足 | 用**管理员**开 PowerShell |
